# QollamOne

Express.js backend application.

## Getting Started

1. Install dependencies:
   ```sh
   npm install
   ```

2. Copy environment variables:
   ```sh
   cp .env.example .env
   ```

3. Run in development:
   ```sh
   npm run dev
   ```

4. Run in production:
   ```sh
   npm start
   ```

## Endpoints

- `GET /` — Application status
- `GET /health` — Health check
- `GET /api` — API root
